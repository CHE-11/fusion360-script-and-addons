## f360-better-parameters

This is a Fusion 360 add-in to make an easier parameter editing experience for fusion 360.

### Install

There is no build step. Fusion runs the Python in this folder.

1. In Fusion, open **Utilities → Scripts and Add-Ins** (or press `Shift+S`).
2. On the **Add-Ins** tab, click the **+** next to **My Add-Ins**.
3. Select this folder (`addons/ce-parameters`).
4. Select **ce-parameters** and click **Run**.

If it was already listed, click **Stop**, then **Run** again after updating the files. The **Better Parameters** button is on the Design workspace **ADD-INS** panel. Click it to open the window. After the first successful run, the add-in starts with Fusion. 

When you select the Add In Icon from the toolbar, it will open a new window. 

The window will have two tabs: Selected Object and All Objects.

The Selected Object tab will show the selected object and its parameters with the ability to edit them. 

The All Objects tab will show all objects in the model and their parameters with the ability to edit them. 

It should be easy to select a parameter and copy the name to the clipboard to be used in a dimension or input.
